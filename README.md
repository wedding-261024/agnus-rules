# 아뉴스 청년회 회칙 개정안 의견수렴

9개 장을 순서대로 열람하며 **변경된 9개 조항**(14·22·23·26·28·29·31·32·33조)만 투표하는 정적 웹 + Google Apps Script 연동 프로젝트.

## 필요한 준비물
- 개인 GitHub 계정
- Google 계정과 새 Google Sheets 파일
- 임원진 실명(세례명 제외), 직책, 각 회원에게 **개별적으로 전달할 초대코드**

## 1. Google Sheets 만들기
1. 새 스프레드시트를 만든 후 `확장 프로그램 → Apps Script` 클릭.
2. 기본 Code.gs를 삭제하고 이 폴더의 `Code.gs` 내용을 붙여넣은 뒤 저장.
3. Apps Script의 프로젝트 설정 → **스크립트 속성**에 `SITE_ORIGIN`을 정확한 GitHub Pages origin으로 설정합니다. **예:** `https://yourname.github.io` (뒤의 `/agnus-rules/`를 붙이면 안 됨). 로컬 테스트 시 사용 중인 로컬 서버 origin으로 임시 변경할 수 있습니다.
4. 편집기에서 `setup` 함수를 선택해 **실행**, 권한을 승인합니다. `Users`, `Responses`, `AuditLog` 시트 생성 확인.
5. `Users` 시트의 **Name**, **Role**, **InviteCode** 열에 회원별 이름·직책·서로 다른 **임의의 긴 초대코드(최소 12자 권장)**를 입력합니다. D~H열은 그대로 둡니다. 동일 이름 사용자가 있으면 구별할 수 없으므로 동일 이름은 별도 아이디 정책을 만들어 수정해야 합니다.
6. Apps Script `배포 → 새 배포 → 유형: 웹 앱`, **실행 사용자: 나**, **액세스 권한: 모든 사용자**를 선택해 배포합니다. `/exec` 주소를 복사합니다. 구글 계정으로 실행되는 서버는 `Users` 시트를 읽으므로 스프레드시트 자체는 공개하지 않습니다.

## 2. GitHub Pages 배포
1. GitHub의 새로운 **public** 저장소를 `agnus-rules` 이름으로 생성합니다.
2. 이 프로젝트의 `index.html`, `styles.css`, `app.js`, `config.js`, `content.json`을 저장소 루트에 업로드합니다. **`Code.gs`는 비밀정보가 없어도 GitHub에 올릴 필요가 없으며 Apps Script에만 붙여넣으면 됩니다.**
3. `config.js`의 `API_URL`에 1단계에서 받은 Apps Script의 `/exec` 주소를 기입하고 커밋합니다.
4. GitHub `Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save`.
5. 표시된 URL(`https://yourname.github.io/agnus-rules/`)로 접속합니다. **SITE_ORIGIN은 `https://yourname.github.io`여야 합니다.**
6. 1명의 테스트 계정으로 최초 등록·로그인·응답 저장·새로고침 후 재로그인을 모두 확인한 다음 개별 초대코드를 배포합니다.

## 3. 실제 이용 방법
- 임원 최초 접속: `최초 등록` → 이름(세례명 제외), 숫자 4자리 PIN, 개인 초대코드 → 등록.
- 이후 `로그인` → 이름과 PIN. 같은 이름 계정이 미리 등록되지 않았다면 가입 불가.
- 변경 없는 장은 원문만 표시하고 건너뜀. 변경된 장은 제14·22·23·26·28·29·31·32·33조 각각 찬성/반대/보류 및 기타의견 입력 가능.
- 제출 후 팝업에서 다음 화면으로 이동하거나 현재 화면 유지. 이전 응답 수정 가능.
- 관리자: Google Sheets의 `Responses` 탭을 필터/피벗 테이블로 집계.

## 참고 및 보안 한계
- **네 자리 PIN은 취약합니다.** 이 구현은 소규모 내부 의견수렴용입니다. 공식적/법적 전자투표 또는 중요한 개인정보 인증에는 사용하지 마세요.
- PIN 원문은 저장하지 않으며 salt+SHA-256 해시를 Sheets에 저장합니다. 다만 PIN 엔트로피가 낮아 Sheets 유출에 취약할 수 있으므로 강한 비밀번호나 Google 로그인을 우선 권장합니다.
- 최초 등록 시 고유 초대코드로 명단을 검증합니다. 초대코드를 단체방에 한꺼번에 게시하지 마세요.
- 시트가 외부에 공개되지 않도록 공유 설정을 점검하고, 필요하다면 Apps Script `웹 앱` 배포를 삭제해 즉시 API를 비활성화하세요.
- Apps Script HtmlService 응답/브라우저 보안정책은 배포 환경에 따라 달라질 수 있습니다. 실제 서버에서 메시지 응답이 작동하는지 테스트가 필요합니다.
- Google Apps Script의 동시 실행, 서비스 할당량에 주의하세요. 소규모 청년회 투표에는 일반적으로 적합합니다.
- PDF에서 텍스트 추출한 원문을 `content.json`에 수록했습니다. PDF의 원문 오탈자는 수정하지 않았으며, 줄바꿈/띄어쓰기는 추출 결과 그대로일 수 있습니다.
- 편집한 Apps Script를 재배포할 때 새 버전 배포/기존 배포 수정 절차를 확인하세요.
