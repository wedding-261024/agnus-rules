# 아뉴스 청년회 회칙 개정안 실시간 투표

발표자(관리자)가 조항을 하나씩 열면, 회원들은 휴대폰에서 **찬성 · 반대 · 기권(보류)** 중 하나를 누릅니다.
결과는 관리자 화면에 **이름과 함께 2초마다** 갱신되고, 모든 기록은 구글 시트에 남습니다.

| 화면 | 주소 | 누가 |
|---|---|---|
| 투표 화면 | 배포 주소 (`…/exec`) | 회원 (아이폰·안드로이드 공통, 앱 설치 필요 없음) |
| 관리자 화면 | 배포 주소 뒤에 `?admin=1` | 발표자 (노트북·프로젝터) |

## 투표 규칙
- 로그인: **이름 + 전화번호 뒷 4자리**
- 투표가 **진행 중**일 때는 몇 번이든 선택을 바꿀 수 있습니다.
- 관리자가 **[투표 마감]** 또는 **[마감하고 다음 조항 ▶]** 을 누르면 그 조항은 잠기고, 더 이상 바꿀 수 없습니다.
- 기명 투표: 관리자 화면과 시트에 누가 무엇을 선택했는지 표시됩니다.

## 처음 한 번만: 설치 (약 15분)

### 1단계. 구글 시트 만들기
1. [sheets.new](https://sheets.new) 에 접속해 새 스프레드시트를 만들고, 이름을 `회칙투표`로 바꿉니다.
2. 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다. 새 탭에 코드 편집기가 열립니다.

### 2단계. 코드 붙여넣기 (파일 3개)
1. 왼쪽 `Code.gs`의 내용을 모두 지우고, 이 폴더의 **`Code.gs`** 내용을 통째로 붙여넣습니다.
2. 왼쪽 **파일 옆 `+` → HTML** 을 눌러 이름을 `Vote`로 입력합니다(`.html`은 자동으로 붙습니다). 안의 내용을 지우고 **`Vote.html`** 내용을 붙여넣습니다.
3. 같은 방법으로 `Admin` 파일을 만들고 **`Admin.html`** 내용을 붙여넣습니다.
4. 💾 저장(Ctrl+S)을 누릅니다.

### 3단계. 시트 자동 구성
1. 편집기 위쪽의 함수 선택 칸에서 **`setup`** 을 고르고 **▶ 실행** 을 누릅니다.
2. "권한 필요" 창이 뜨면 **권한 검토 → 본인 계정 선택 → 고급 → 회칙투표(안전하지 않음)로 이동 → 허용** 을 누릅니다.
   (본인이 만든 코드라서 나오는 일반적인 안내입니다.)
3. 시트로 돌아가면 `회원`, `조항`, `투표기록`, `결과`, `설정` 탭이 생겨 있습니다.

### 4단계. 회원 명단 넣기
1. `회원` 탭의 **A2 칸**을 클릭하고, 따로 전달한 회원 명단(이름 / 전화번호 뒷 4자리)을 붙여넣습니다.
2. 번호가 `0054`처럼 0으로 시작해도 그대로 보이는지 확인합니다.
3. `설정` 탭의 **관리자 비밀번호**(기본값 `1234`)를 원하는 값으로 바꿉니다.
4. 필요하면 `조항` 탭에서 조항 제목이나 한줄 요약 문구를 고칠 수 있습니다. 위에서 아래 순서대로 투표가 진행됩니다.

> ⚠️ 회원 명단(전화번호)은 GitHub에 올리지 마세요. 구글 시트에만 넣습니다.

### 5단계. 웹 앱으로 배포
1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴 ⚙ → **웹 앱** 을 고릅니다.
3. **실행 사용자: 나**, **액세스 권한이 있는 사용자: 모든 사용자** 로 설정하고 **배포** 를 누릅니다.
4. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사합니다.
   - 투표 링크: 이 주소 그대로
   - 관리자 링크: 이 주소 뒤에 `?admin=1`

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포** 를 눌러야 반영됩니다. 이렇게 하면 주소는 바뀌지 않습니다.

## 리허설 (꼭 해보세요)
1. 노트북에서 관리자 링크를 열고 비밀번호로 들어갑니다.
2. 내 휴대폰에서 투표 링크를 열고 내 이름과 번호로 입장합니다.
3. 관리자 화면에서 **▶ 투표 시작** → 휴대폰에서 찬성 → 반대로 바꾸기 → 관리자 화면 숫자가 바뀌는지 확인합니다.
4. **마감하고 다음 조항 ▶** → 휴대폰이 다음 조항으로 넘어가는지 확인합니다.
5. 리허설 기록 지우기: Apps Script 편집기에서 함수 **`resetAll`** 을 선택하고 ▶ 실행합니다. 모든 표가 지워집니다.

## 당일 진행 순서
1. 관리자 화면을 프로젝터에 띄웁니다.
2. **[링크 복사]** 를 눌러 단톡방에 투표 링크를 공유합니다. 회원들은 입장한 뒤 "기다려 주세요" 화면에서 대기합니다.
3. 조항을 설명하고 **▶ 투표 시작** 을 누릅니다.
4. 미투표 명단이 줄어드는 것을 확인한 뒤 **마감하고 다음 조항 ▶** 을 누릅니다.
5. 9개 조항을 마치면 **[결과 다운로드]**(엑셀에서 열 수 있는 CSV) 또는 `결과` · `투표기록` 탭을 확인합니다.

### 이럴 땐 이렇게
| 상황 | 방법 |
|---|---|
| "이름 또는 번호가 맞지 않습니다" | `회원` 탭의 이름 철자와 번호를 확인한 뒤 관리자 화면에서 **[시트 변경 반영]** 을 누릅니다. |
| 마감된 조항을 다시 받아야 할 때 | 왼쪽 목록에서 그 조항을 누르고 **이 조항 다시 열기** 를 누릅니다. 기존 표는 유지되고 수정만 다시 가능해집니다. |
| 한 조항을 처음부터 다시 | **이 조항 표 초기화** 를 누릅니다. |
| 휴대폰 화면이 멈춘 것 같을 때 | 새로고침하면 자동으로 다시 로그인됩니다. |
